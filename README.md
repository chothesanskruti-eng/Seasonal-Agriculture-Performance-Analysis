# Seasonal Agriculture Performance Analysis

## Overview
This repository contains a data analytics and machine learning pipeline evaluating agricultural performance across Kharif, Rabi, and Zaid seasons.

## Directory Structure
- `data/`: Contains dataset files.
- `notebooks/`: Contains executable Jupyter Notebooks.


## Tech Stack
- Python 3.x, Pandas, NumPy, Matplotlib, Scikit-Learn

## Model Performance
- Random Forest Regression R² Score: 0.4815
- RMSE: 381,406.18 INR
